# 评测数据

仓库不附带 benchmark 原始数据。GAIA、HLE 等数据集的发布方要求不要公开转载题目和答案（防止污染训练数据），其余数据集也各有许可证，请到官方渠道下载后放到本目录：

| 数据集 | 官方地址 |
|------|------|
| GAIA | https://huggingface.co/datasets/gaia-benchmark/GAIA （需登录并同意使用条款） |
| HLE（Humanity's Last Exam） | https://huggingface.co/datasets/cais/hle |
| API-Bank | https://github.com/AlibabaResearch/DAMO-ConvAI/tree/main/api-bank |
| ToolBench | https://github.com/OpenBMB/ToolBench |

评测方法和结果见 [wiki/评测部分.md](../wiki/评测部分.md)。
