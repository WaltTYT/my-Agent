# 计划模式联网功能使用示例

## 概述
`/plan` 命令现在支持联网功能，可以在制定计划时搜索最新的信息、文档和最佳实践。

## 新增功能

### 1. 网络搜索 (`search_web`)
- **用途**: 搜索最新的技术文档、最佳实践、示例代码
- **参数**:
  - `query`: 搜索查询字符串（必需）
  - `max_results`: 最大返回结果数（可选，默认5）
- **示例**: 搜索 "React hooks 最佳实践"

### 2. 网页内容获取 (`get_web_content`)
- **用途**: 获取特定网页的内容摘要
- **参数**:
  - `url`: 网页URL（必需）
  - `max_length`: 最大内容长度（可选，默认2000）
- **示例**: 获取 React 官方文档的特定页面

## 使用流程

1. **进入计划模式**
   ```
   /plan
   ```

2. **探索代码**（使用现有工具）
   - `read_file`: 查看项目文件
   - `list_files`: 列出文件结构
   - `grep_search`: 搜索代码

3. **研究最新信息**（新增联网功能）
   - 使用 `search_web` 搜索相关技术文档
   - 使用 `get_web_content` 获取特定页面内容

4. **制定计划**（写入计划文件）
   - 包含研究发现的最新信息
   - 提供相关文档链接
   - 基于最佳实践设计实现方案

5. **退出计划模式**
   - 完成计划后调用 `exit_plan_mode`
   - 系统会显示计划内容供用户审批

## 注意事项

1. **网络依赖**: 联网功能需要网络连接
2. **错误处理**: 如果网络不可用，工具会返回友好的错误消息
3. **内容限制**: 搜索结果和网页内容都有长度限制
4. **安全考虑**: 仅用于信息获取，不会执行任何网络操作

## 优势

- **信息最新**: 可以获取最新的技术文档和最佳实践
- **决策支持**: 基于最新信息制定更合理的计划
- **参考完整**: 计划中包含相关文档链接，便于后续查阅
- **减少猜测**: 避免基于过时信息做出错误决策
